# Google Maps attribution asset

`google-maps-attribution.png` is the unmodified `GoogleMaps_Logo_WithLightOutline_2x.png` from Google's official [Maps attribution asset archive](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip), downloaded 2026-10-01.

Used only to attribute Google Maps content. Displayed at 18 CSS pixels high with its original aspect ratio and clear space, following the [official attribution guidance](https://developers.google.com/maps/documentation/places/web-service/policies). This is a branding asset, not a cached Places photograph.
